8. THE MOVING "NO" BUTTON SYSTEM

This is a signature LOVELOCK feature.

Create a reusable component called "PlayfulNoButton" that can be used in quizzes and challenges.

It must support these modes:

NORMAL

The button behaves normally.

PLAYFUL

When the user moves their pointer near the "No" button, it moves to a new safe position within the quiz card.

On touch devices, tapping the button triggers a playful movement instead of immediately selecting it.

ESCAPE MODE

The button tries to evade the pointer or touch interaction by moving to a different safe position inside its container.

Keep movement smooth and unpredictable without causing layout overflow.

DISABLED

The button remains visible but cannot be selected. Clearly communicate its disabled state.

Configuration

Quiz creators should be able to choose the button mode for individual questions.

For the default Girlfriend Challenge, use PLAYFUL mode for questions with a "No" option.

Technical requirements

- Keep the button within its parent container.
- Never allow it to cover important text or other answer options.
- Avoid placing it outside the visible screen.
- Prevent horizontal page overflow.
- Make sure other answer options remain clickable.
- Avoid infinite animation loops that waste resources.
- Respect reduced-motion settings.
- Provide keyboard accessibility and an accessible alternative interaction.
- Ensure the experience remains usable on phones and tablets.
- Store the actual answer selected by the participant.
- Do not automatically convert an unanswered question into "Yes."
- Never silently submit an answer without the participant's action.

On touch devices, a tap on the playful button may make it move. Provide a clear accessible way to complete the quiz without making the interaction impossible.
